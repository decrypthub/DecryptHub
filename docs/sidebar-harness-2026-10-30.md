# 侧栏项目管理与搜索：Harness 对照

日期：2026-10-30。延续 [项目与目录生命周期](project-navigation.md)，不改变会话必须属于项目和目录的约束。

## 参考依据

本机 DeepSeek Harness 0.2.1-rc.3 与源码快照 `f3803c96974ad4a94195fb97e5c637e9c2a3afe3`：`packages/client/ui-workspace/src/client/rows/WorkspaceBrowser.tsx`、`Rows.tsx` 及对应样式、`tree.ts`、`stores.ts`。实机检查了侧栏搜索、项目匹配、结果所属工作区和选中结果后恢复项目树的流程；没有修改参考应用的项目、目录或会话内容。

Harness 点击搜索图标后，将工作区标题一行替换为输入框；空查询保留项目树，输入关键词后显示会话结果。先匹配已有元数据，再延迟 250ms 检索历史；结果第二行显示所属工作区与摘录。点击结果会清空搜索、返回树并揭示所选会话。默认每项目显示五条会话，选中与活动会话可以提高显示范围，提供继续展开入口。

其视图支持工作区、工作区树及单列表，排序支持手动与最近更新。本产品沿用已确认的单层项目模型，仅提供“按项目 / 全部会话”和“手动排序 / 最近更新”；不添加无项目会话或只有外观、没有后端生命周期的归档功能。

## 本次实现

- 项目与会话采用紧凑行，无包围卡片、无额外右移的项目容器。项目行 34px，仅显示文件夹和项目名称，移除前置展开箭头；整行点击与左右方向键继续控制折叠。会话保留 16px 空图标位并与项目名称对齐，运行时在该位置显示状态。悬停、键盘聚焦或菜单打开时显示管理按钮；会话行悬停隐藏时间并显示操作，避免长标题被两组按钮同时挤压。
- 顶部搜索、视图、新建三个按钮使用无负边距的安静样式，按钮间距 8px，保留完整点击区域；不覆盖 Radix 的内部尺寸变量。
- 项目可展开、收起、在其中新建会话、手动拖动排序。默认五条，选中或活动会话可自动显示，支持展开剩余项。视图菜单提供全部展开 / 收起。最近更新排序不会覆盖保存的手动项目顺序。
- 项目菜单支持重命名、编辑、重新连接目录、复制路径、上下移动及删除。重命名使用独立的小对话框。项目与会话均支持右键和 Shift+F10；会话保留置顶、重命名、移动项目、导出和删除入口。
- 搜索按钮或 Cmd/Ctrl+K 在侧栏内打开搜索，侧栏收起时先展开。标题、项目名和目录即时匹配；250ms 后异步搜索本机会话正文。结果显示所属项目和命中摘录。空项目本身也有搜索结果，便于直接管理。
- 上下键选择、Enter 打开、Escape 或清除按钮关闭。选中项目只揭示并展开项目，不擅自切换会话；选中会话返回树、展开项目、显示所选行，正文命中有稳定轮次 ID 时滚动至该轮。键盘选择是本产品实现，不将其描述为参考应用已完成的原生验收。
- 分组、排序与项目折叠使用本地呈现偏好，不改变项目 / 会话的稳定 ID。全部会话视图仍显示项目归属。

## 搜索边界

`sidebar-model.js` 负责即时匹配与结果合并；`sidebar-browser.jsx` 负责交互；`session-search.mjs` 负责只读历史检索，RPC 只转接协议。搜索不启动 Agent、不调用模型、不读取项目源码、附件或工具原始载荷，不搜索隐藏思考和内部状态提示。

单条查询最多 500 UTF-16 字符；普通历史文件上限 8MiB，每查询读取 / 检查预算 32MiB，结果摘录约 180 字符。非普通文件、链接、损坏或超限记录跳过，界面提示部分记录未能搜索。因此不承诺无限大小历史的完整全文索引。

同连接新查询取消旧查询，连接关闭取消检索；前端关闭或更改搜索后丢弃晚到结果。读取后重新确认会话对象与项目归属，删除、移动后的结果不能带着旧归属发布。UI 合并时再过滤不存在或归属已改变的会话。

删除项目继续遵循已有的迁移 / 显式连同会话删除流程，外部源码目录保留。目录失效保留历史、停止执行，重新连接仍须原生目录授权。本轮没有变更权限、执行边界或原生窗口后端。
