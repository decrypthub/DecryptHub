# 项目、多目录与可扩展 Harness

2026-10-26 实施决定。参考官方项目行为说明：https://learn.chatgpt.com/docs/projects 。

## 范围和兼容

新会话的目录状态为“待选择”，不创建代码工作目录。用户选择文件夹/项目，或明确选择“不在目录中工作”后，才激活用户目录或会话临时工作目录。私有历史/附件目录仍随会话存在，它不等于已选择的代码目录。旧会话已有的目录绑定保持有效，目录切换不移动或删除文件。

项目是独立持久化实体，含稳定 ID、名称、一个主目录和多个附加目录。目录只由原生选择器凭证登记，模型不能自行扩大文件访问范围。主目录决定命令 cwd 和文件写入位置；附加目录通过文件工具明确选根读取/搜索。会话可加入或移出项目；加入时更新目录上下文，原对话保留。运行或排队中的会话阻止项目目录变更，切换沿用浏览器/子代理/目标的取消边界。

## 交互和命令

项目选择、项目编辑、权限和执行环境均使用悬浮面板/弹窗，不占据输入框上方的展开高度。命令保留草稿和附件，执行中/成功/失败都有可见反馈；无参数的目标命令显示输入弹窗，压缩说明历史不足或缺少模型配置的原因。

新增技能、记忆、自动化、MCP 命令与实际管理工具。技能和记忆按用户/项目/会话保存，通过有界目录索引和显式读取进入模型上下文。写入采用固定命名/路径边界和覆盖校验。管理 MCP 和自动化沿用生产配置服务；标准权限下的持久管理操作需要批准，完全访问遵循当前授权，自动化不能自行获得完全访问。

自动化重启后将未完成任务标为中断，不自动补跑关闭期间错过的排期。运行中不能编辑/删除任务；状态变化即时通知界面，缺少目录、模型或审批时显示待处理。设置文件通过原子替换保存，避免一次管理操作留下半个 JSON。

## 验收退出条件

- 新会话不提前建立工作目录；选择/跳过、旧数据恢复和草稿保留通过。
- 项目多根读取、主目录写入、未知根/越界/链接/敏感文件拒绝以及会话切换隔离通过。
- /goal、/compact 和扩展命令经输入框执行，成功/失败/空参数可见。
- 自动化保存校验不留下半修改，重启可恢复中断状态，真实 Run 完成/权限受阻能回写状态。
- 全部核心测试、UI 构建/控件审计/浅深色交互与原生窗口必要检查完成；尚未通过的项不得写作已交付。
