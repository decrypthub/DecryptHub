# Harness 风格的桌面工作区

2026-10-28。用户要求以提供的 DeepSeek Harness 截图及本机应用为视觉参照，优先使用沉浸式 Mac 窗口和默认展开的左侧栏。

## 参考与边界

- 参照本机 DeepSeek Harness 0.2.1 和官方开源仓库 https://github.com/deepseek-ai/deepseek-harness ，阅读快照为 `f3803c96974ad4a94195fb97e5c637e9c2a3afe3`。桌面实现采用 hiddenInset 原生红黄绿、侧栏窗口区与中间内容分栏；本项目用 Tauri 对应能力独立实现。
- 不复制 DeepSeek 标识、账号信息、会话内容或源代码。保留 DecryptHub 品牌、React/Radix 和现有域模块；不更换桌面框架、浏览器控制或权限体系。
- 本轮不伪造账号菜单、轨迹页、后台任务数量或吞吐指标。既有执行过程、上下文、审批、项目、多文档、浏览器/网络和终端功能继续保留。

## 第一轮改动

1. Mac 启用 overlay 原生标题栏、隐藏系统居中标题，将原生窗口按钮置于侧栏顶部区域。内容向顶部延伸，不再叠一条独立系统标题栏。关闭侧栏时给左上角留出原生按钮安全区。
2. 左侧会话栏首次默认展开；兼容 `wdh_rail` 的 open/closed，明确保存的折叠选择仍然生效。存储不可用时仍能使用界面。
3. 导航分为窗口操作区、DecryptHub 标识、中性新对话按钮、插件/自动化、工作区、会话、底部本地设置。工作区与会话仍使用原有稳定 ID，不做存储迁移。
4. 使用系统字体和中性灰阶，弱化大面积品牌红，保留警告/完全访问权限的语义颜色。正文、输入区和工作目录提示使用一致的宽度轴，输入容器仍保留既有 22px 圆角与可访问控件。
5. 会话顶部显示真实访问模式；只改变呈现，不改变审批或执行规则。右侧工具仍按会话按需打开，不默认占用主阅读区。
6. 修复新建终端时菜单关闭恢复焦点与 PTY 就绪焦点的竞态：仅在选择终端时阻止菜单抢回触发器焦点，Esc 取消和其他菜单项保留 Radix 默认行为。回归使用终端自然获得的焦点输入，不强行 focus 掩盖问题。

## 验收与退出条件

- 偏好测试覆盖默认打开、已保存折叠/展开及存储不可用；UI 回归验证折叠重载、再次展开、侧栏/工具栏和所有已有功能。
- Mac 布局分别验证有/无侧栏和设置页的原生按钮预留区域；深浅主题及小窗口需要视觉和命中区域检查。
- 完整 sidecar、UI build/audit/check 与 Rust 测试通过，真实 Mac 确认 overlay 原生按钮与内容不重叠。
- Mac 验收不能替代 Windows 原生窗口测试；Windows 仍使用原有无边框控制，不操作用户 Windows 桌面。
- 本轮侧栏为不透明应用材质，不宣称已实现 AppKit vibrancy；原生透明材质需要单独兼容性验证。

## 本机验证结果

235 项 sidecar 测试中 232 通过、3 项 Windows 专用跳过；UI build/audit、深浅主题完整交互和 9 项 Rust 测试通过。1280px 输入框底部安全间距保持大于 20px，不通过放宽断言掩盖贴边问题。终端 UI 用自然获得的焦点完成真实 printf 输入，关闭菜单后回车不再误开菜单。

真实 Mac 已通过 Computer Use 对照参考应用并检查新窗口：原生系统按钮仍存在，额外标题行消失；侧栏可展开/折叠，折叠后顶部留有安全区；开发工作区与会话未迁移。未操作 Windows 桌面，未把这些结果当作 Windows 原生显示验收。
