## 唯一正常创建链路

1. 没有项目、会话时显示项目空状态，索引为空；不创建隐形或无归属草稿。
2. 原生选择器为一次项目编辑范围签发目录凭证。后端校验签名、有效期、单次消费以及目录身份，保存项目。
3. 在已有项目中创建会话。RPC 必须携带 projectId；恢复会话也必须有有效项目注册，不从 cwd、URL 或其他会话推断归属。
4. 自动化绑定项目内的已有会话，不提供独立托管工作区。删除最后一个会话或项目不会补建新会话。

已移除无项目导入、自动补归属模块、内部启动草稿、workspace-set 及可选目录模式。开发数据不符合当前约束时明确报错，由开发者清理，不在产品里维护一套平行会话系统。本机两个无项目空白会话已经通过正常删除流程清理。

## 目录失效和恢复

项目仍有稳定 ID，目录状态另为 ready、missing、changed 或 unavailable。后端定期检查主目录，每次文件、执行、浏览器和终端操作仍独立验证目录；检查器不是执行授权边界。

- 目录删除、移动、挂载断开或权限失效：项目和会话仍在原位置，显示目录不可用，保留历史；停止 Agent、目标驱动、排队任务、终端及浏览器，不重建原路径。
- 原目录以同一身份恢复：显示可用；任务不会自动恢复或重放。
- 原路径被新目录占用：即使路径字符串相同，身份变化也不能自动接受，需重新选择目录。
- 重新选择目录：取得新原生授权，在项目事务内关闭所属资源、撤销旧操作授权，更新项目全部会话的目录绑定和修订。项目 ID、会话 ID、聊天历史和草稿保留；旧产出不移动、不复制、不删除。
- 删除项目：可迁移会话到另一个有效项目，或明确删除其中会话并暂停关联自动化；外部源码目录不属于删除目标。

未承诺抵御同用户恶意程序持续替换路径的全部 OS 竞态。已有执行、敏感路径、符号链接和变更哈希边界继续适用。

## 导航和 Mac 窗口

默认侧栏显示项目及其可折叠会话；项目顺序用稳定 ID 和 beforeId 持久化。侧栏宽度和展开状态属于本地呈现偏好，左右开关分别为左窄右宽、左宽右窄。2026-10-30 增加带项目归属的全部会话视图、最近更新排序和内联项目 / 会话内容搜索，详见 [Harness 侧栏对照](sidebar-harness-2026-10-30.md)。

Mac 使用 AppKit 原生按钮。Harness 的 Electron hiddenInset 使用 x16/y18；Tauri/Tao 的 y 参数实际用于标题栏容器高度，不能只抄数值认为视觉位置相同。本次 Tauri inset 改为 x20/y24，在 56px 顶栏内增加左侧和顶部留白；折叠侧栏继续保留 104px 按钮安全区，不重绘红黄绿。
