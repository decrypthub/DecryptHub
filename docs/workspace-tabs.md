# 会话工作标签页

2026-10-28。将固定工具页签改为每会话独立的工作标签页，沿用React/Radix、BrowserSurface和现有WDH协议。

- 权限使用带说明和选中状态的菜单。执行环境详情单独按需查看；完全访问的首次确认与后端审批边界保留。项目选择菜单保留搜索、新建、选择文件夹和不在目录中工作；复制路径放入文件工具栏。
- 标签页为稳定ID，类型为文件目录、文档、浏览器、终端。新增、切换和关闭独立；关闭查看标签不会删除磁盘文件。每会话保存标签顺序与所选标签，旧版固定页签偏好迁移。
- 浏览器仍由每会话一个WDH进程管理，浏览器标签绑定真实page ID；同一时间仅呈现当前页面。网页和网络请求为同一浏览器标签的子视图，网络捕获数据仍为会话范围。切换请求按最新意图串行；晚到结果不能切换另一个会话。所有原生呈现继续经过BrowserSurface，不注入网页。
- 文件阅读通过现有工作区边界；相对路径或工作区内的绝对路径可从消息点击打开，拒绝目录外路径、链接和危险URL。Markdown以受约束渲染器预览，可查看源码；同一路径重复打开复用标签。文件标识包含工作区版本，换目录后旧文档不能误读同名新文件。
- 交互终端采用xterm.js与node-pty；每个原生PTY运行在独立Node worker中，避免原生线程残留拖住Harness；由终端服务拥有生命周期，Executor负责实际启动与取消。终端属于会话与工作区版本，既不复用模型Run，也不把命令输出当模型指令。标准模式启动需明确批准宿主终端，只读禁止，完全访问直接启动。输入、输出和数量均有限额；关闭/删除会话、切目录或降权限取消启动并结束所属进程。重启不自动执行或恢复shell。
- 终端不是OS隔离，不向Agent注册任意终端输入工具，不开放网页可调用的未鉴权入口。打包必须携带匹配平台的PTY原生依赖并验证真实输入/退出链路，不能以模拟输出替代终端。

退出条件：状态迁移、标签关闭与重载、跨会话隔离、过期文件读取、浏览器切页竞态、终端审批/输入/取消/目录切换/打包测试；深浅主题与真实Windows原生浏览器遮挡切换验收。
