# DecryptHub 项目历史和记忆要求工作区归属

[English](guide.md) | 中文

## 变更

此前，未归属工作区的聊天可能列出其他工作区的历史，缺少归属的旧项目记忆也可能出现在其他工作区。现在工具依据当前会话的工作区归属授权。按 ID 更新项目记忆会保留原作用域。归属待确认的记忆仍保留在设置中。

## 迁移

1. 从目标工作区打开对话，再使用 `session_list`、`session_read` 或写入项目记忆。
2. 在设置的记忆页核对旧条目。需要恢复归属不明的项目条目时，先核对内容，再从目标工作区的对话保存。
3. 确认历史和项目记忆只在目标工作区出现。
