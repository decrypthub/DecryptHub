# 对话内容、轮次索引与子代理呈现

2026-10-29。按用户要求参考本机 DeepSeek Harness 及开源快照 `f3803c96974ad4a94195fb97e5c637e9c2a3afe3` 的 TurnNavigator、TurnProcessNodeView、MessageItem 和子代理入口设计，使用本项目 React/Radix 实现。

## 版面与交互

- 每轮顺序为用户输入、执行过程、模型正文。工具调用之间模型输出的进度说明按真实顺序留在执行过程里，与工具行交错；折叠的是整个 Agent Loop，最终回复在过程之外始终可见。所有轮次的执行过程都收成一行摘要（状态、耗时、按动作归类的统计，如「思考 · 读取页面 8 · 写入文件 8」），完成的轮次默认收起，进行中及中断/失败、等待批准或回答的轮次默认展开。正文不放入工具卡片。
- 展开后的执行过程限制在 min(48vh, 480px) 内独立滚动，不再把整页顶走；每行只占一行：思考显示首行预览、中间说明单行省略，工具行显示动作、参数摘要、状态和耗时，点开行才看完整内容。
- 思考过程默认收起，只有模型明确返回的可读思考才占一条摘要行；进行中显示「正在思考」，展开后实时增量显示。
- 工具摘要为动作、对象、耗时及状态；展开后分开显示输入、输出并可复制。长输出在详情内滚动，不拉长整个对话。模型思考仅呈现服务端已有的可读内容，不生成额外推理。
- 两轮以上在消息区右侧显示固定 12px 间距的刻度，当前可见轮次高亮；悬停或键盘聚焦预览输入与回复，点击/Enter 跳转，上下键及 Home/End 选择。刻度过多时独立滚动并按可见窗口渲染，不把百轮压缩成无法点击的细点。
- 索引是消息滚动区的兄弟元素，其高度随实际消息区测量，上限 420px。它不跨越输入区，窄窗仍保留入口与消息右侧留白；遵守减少动态效果的系统偏好。
- 子代理从输入区移除。对话标题右侧保留小型计数入口，展开列表/结论；有 `parentRunId` 的子代理同时归入对应轮次的执行过程。无父轮次记录保留在顶部列表，不按时间或标题猜测归属。
- 子代理详情按当前会话与任务独立请求，关闭或切换后忽略晚到结果；任务完成时刷新结论。详情和列表限制尺寸，展开不会推挤输入区。

## 模块与兼容

`conversation.js` 只派生轮次呈现和父子关系，不改模型历史；`turn-navigation.js` 负责索引几何与短预览，`turn-navigator.jsx` 管滚动/焦点；`subagents.jsx` 管子代理呈现。侧车的执行权限、预算、工具协议和持久化格式不变。

既有无 turnId 记录优先用消息 ID 作为显示身份；没有消息 ID 时保留位置回退。已有 Run/工具 ID 不变，不引入会话存储迁移。测试专用 `test-seed-history` 仅在 `JSRA_TEST_FIXTURES=1` 时允许植入已结束的子代理示例，不启动研究任务。

## 2026-10-30：短过程直显与摘要宽度

按用户要求，继续核对 Harness 的 `ChatNodeSeat`、`ChatGroupSeat` 和 `TurnProcessNodeView`：其展示由折叠策略、内容归属、任务状态和用户选择共同决定，源码并非简单按会话字数截断，也未提供可直接照抄的统一字数阈值。本项目将“短轮次无需摘要”作为明确的本地显示偏好实现。

- 少量操作、简短过渡消息或思考直接显示；纯输入/回复不再额外生成已结束的过程耗时行。
- 达到 8 个过程条目、6 次工具调用、1600 字符的过渡/可读思考，或 4 个子任务之一时，才启用整组折叠。工具原始输出已有独立展开，单个超长结果不单独导致整个短轮次被隐藏。这些数值是本项目的展示起点，不宣称是 Harness 的默认规则。
- 进行中、失败、中断及需处理的长轮次默认展开，用户仍可主动收起。短过程增长为长过程时保持相同父容器，不重置已经打开的工具详情。
- 整组摘要使用消息列的可用宽度，状态/耗时优先保留完整显示；空间不足时优先省略次要统计。折叠规则位于 `process-presentation.js`，只控制呈现，不改变模型上下文压缩、历史内容或权限。
- 回归分别使用真正的短过程与较长过程；检查完整的“用时 25 分 51 秒”、短思考完成/刷新后仍可见、长过程可键盘展开/收起。不要通过把所有示例重新当成长过程来掩盖短轮次行为。
