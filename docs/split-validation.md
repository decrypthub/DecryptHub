- DecryptHub：170 项核心测试，169 通过，1 项因当前机器缺少完整隔离后端而跳过；未将该后端标为已完成验收。
- WDH：24 项测试通过，包含实际 MCP 浏览器打开、请求抓取、脚本搜索、断点命中、单步和恢复。
- 系统 Chrome 与已安装 CloakBrowser 分别通过独立 MCP 测试。跨仓源码路径、实际安装组件均通过宿主联调；关闭期间的启动取消不留下 MCP 客户端。
- UI：生产构建、Radix 命中区域审计、浅色/深色契约通过；包含图片、会话菜单、工作区、抓包响应详情和浏览器 AI 操控边框。
- Windows：本地调试构建通过；真实 Tauri → Node → WDH → 系统 Chrome / Cloak 有头链路通过，DOM/抓包/调试通过。旧内核低完整性恢复只处理测试中复制的内核代码；启动参数未关闭 Chromium sandbox。
- Windows 核心生产 bundle 约 0.8 MB，不包含 Patchright/js-reverse-core；实际捆绑 Node 启动通过，未安装 WDH 时正常显示组件诊断，拒绝加载工作目录 preload。
- 组件构建不含浏览器二进制；本地安装校验全部文件 SHA-256、平台与 API，再原子激活。损坏文件不会替换激活版本。提交扫描未发现凭据模式、抓包数据、node_modules 或二进制运行文件。
- WDH 和桌面 UI 生产依赖审计未发现漏洞；核心 SRT 依赖链仍有 3 条 high（聚合项、node-forge、旧 Zod），详见 security.md。
