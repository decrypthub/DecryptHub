# 桌面交互收敛与浏览器操控遮罩

日期：2026-10-28。实施边界与验收决定。

- 浏览器提示属于宿主显示层，绝不注入被分析网页的 DOM、CSS、JS 或初始化脚本，不改变浏览器工具和 CDP 控制契约。
- 串流使用宿主 UI 的半透明渐隐遮罩；Windows 原生嵌入使用浏览器宿主子窗口中的独立、无焦点、鼠标穿透 layered window。遮罩限制在网页显示矩形内，边缘向内渐隐，不预留粗边框、不改变视口大小。
- 原生显示、隐藏、会话切换和释放继续经过 BrowserSurface 队列；遮罩与宿主同生命周期。系统不支持原生遮罩时使用现有串流回退，不向网页注入替代物。参考 [Windows layered windows](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows) 与 [UpdateLayeredWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow)。
- 输入容器采用自有背景/边框统一绘制22px圆角，不覆盖 Radix 私有变量或伪元素；基础按钮与选择器继续使用 Radix。
- 地址栏由回车导航，保留后退、刷新、菜单与加载反馈。聊天标题不展示网址副标题。
- 网络请求数量统一为当前会话全部已记录请求，页签只展示一次。工具条保留搜索和明确的抓取状态操作，筛选使用有间距、可横向滚动的选项组，不用无间距 ghost 按钮排列。
- 抓取操作以服务端状态为准，待完成时禁用重复提交，错误时保留原状态；暂停与继续采用不同图标和名称。消息输入仅有一个发送/停止按钮，键盘回车仍可提交运行期间的补充要求至队列。
- 工作区内以本地文件/Git改动子页签切换，文件预览归属所选页签，切换取消过期读取。没有Git仓库不影响本地文件浏览。
- UI 使用新的 session-delete，旧 session-close 保留兼容。删除先取消主任务、子代理、目标、标题生成和浏览器，并等待所属任务结束，再删除固定应用数据目录下该会话的私有目录与按ID定位的旧版持久浏览器配置（chrome-profile 或 profiles/会话ID）。两处均先检查链接替换；不得从 workspace.root 或浏览器返回路径推导删除目标。外部项目目录保留；会话内托管工作区会一并删除，确认文字明确说明。相关自动化暂停并保留定义。
- 删除不能自动作用于旧版已关闭但未列出的数据；本轮不批量清理用户历史。拒绝链接替换的会话根目录，失败时不隐藏清理失败，重试可继续；同用户恶意程序持续替换路径的 OS 级竞态仍不是本应用的完整防护承诺。

验收：生命周期/协议/删除范围测试、完整 sidecar 测试、UI构建/审计/深浅主题交互，输入框四角截图，真实Windows原生遮罩的显示/淡出/切换/鼠标穿透/视口与网页DOM不变检查。所有删除用独立测试会话，不清理用户当前会话。

本轮记录：221项sidecar测试、9项Rust测试通过；UI深浅主题验证本地/Git页签、删除确认与重载不复活、抓包状态转换、单一发送/停止控件。Windows独立窗口确认原生宿主与ActivityOverlay同时存在，遮罩边缘按钮可点击、输入框可输入，结束后淡出、收起后隐藏。原生窗口之前存在DOM焦点与Win32键盘焦点不一致，现仅在点击所属Chrome窗口时交接线程焦点。测试页面中的输入与点击控件由本地HTTP固定fixture提供，遮罩代码不接触CDP或页面。未据此宣称所有DPI、IME或平台组合均已验收。
